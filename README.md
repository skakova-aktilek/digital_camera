# Digital Camera

Lightweight camera capture utilities for embedded and desktop use.

Features
- Camera initialization and configuration (resolution, framerate)
- Frame capture loop with JPEG encoding and safe disk write
- Basic error handling and logging
- Example usage and simple tests

Quick start

1. Ensure camera device permissions are available on your platform.
2. Install dependencies (if any) — see project files.
3. Run the example:

```bash
python helloworld_1.py
```

Notes
- Hardware-specific drivers may be required for embedded targets.
- See `commit_message.txt` for recent high-level changes.
